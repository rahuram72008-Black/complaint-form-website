Complaint Form Website

About

A simple and responsive Complaint Form Website built using HTML and CSS. Users can enter their name, email, department, and complaint details.

Features

- Name and email input fields
- Department selection
- Complaint details text area
- Required field validation
- Clean design with CSS styling

Technologies Used

- HTML5
- CSS3

Departments

- Electricity
- Water Supply
- Roads

Purpose

This project was created as a beginner web development learning project.

Note

This is a front-end demo only. It does not store or send complaints to a server.
